Website policy

Privacy

A static product site with no document uploads.

Last updated July 14, 2026.

Website hosting

This website is deployed through GitHub Pages. GitHub may process request information such as IP addresses, browser details, requested URLs, and timestamps as part of hosting, security, and service operation. Review the GitHub Privacy Statement for details.

No document processing

The public website does not accept Markdown files, PDF files, or arbitrary document content. The output examples are static files generated before deployment.

API beta requests

The beta request form prepares a GitHub issue URL in the browser. Information is not sent automatically. The visitor reviews and explicitly submits the issue through GitHub, where it becomes public. Requests must not contain confidential information, customer data, documents, credentials, or private infrastructure details.

Analytics and cookies

This initial website does not include product analytics, advertising trackers, session recording, or first-party cookies. GitHub Pages may apply its own service-level processing as described in GitHub's policies.

External links

Links to GitHub releases, documentation, issues, and other websites are governed by the privacy practices of those services.

Hosted API

The hosted RayoMD API is not generally available. A separate privacy policy, retention specification, and operational terms must be published before accepting production documents.

Questions

Privacy questions can be raised through the RayoMD issue tracker without including sensitive personal information.
