The native path

Ship PDFs, not Chromium.

RayoMD parses Markdown and writes PDF bytes directly, in its own C++17 code. It typesets formulas, colours code and draws diagrams itself: nothing starts a browser, a TeX installation, or Pandoc.

01 Markdown bytes # Report
02 Native parse + layout C++17
03 Valid PDF bytes %PDF-1.7
  • TeX math typeset natively
  • Code coloured in 29 languages
  • Mermaid diagrams drawn as vectors
  • PDF/A-3b and PDF/UA-1
  • Linux binary needs only libc

Focused workloads

Small engine. Specific jobs.

01

CI documentation

Turn release notes, manuals, and whole folders of repository Markdown into reproducible build artifacts, on up to 64 threads.

rayomd --batch docs pdf-out --recursive --skip-unchanged
02

Generated reports

Convert Markdown from backend jobs or AI pipelines without maintaining a browser pool. A running process exports each further document in 0.16 ms.

cat report.md | rayomd --stdin report.pdf
03

Books and notes

One PDF from an mdBook or GitBook SUMMARY.md, a folder, or an Obsidian note and the notes it links to, with one table of contents.

rayomd --book SUMMARY.md book.pdf --toc --page-numbers
04

Local and embedded tools

Keep conversion offline and link the C++ exporter into your own application, as RayoMD GUI does.

#include "rayomd/tiny_pdf.h"

Deliberate scope

Fast because the job is smaller.

RayoMD renders a Markdown subset, not every document format. Unsupported input degrades to readable output instead of failing the export.

Use native RayoMD for

  • GitHub-style Markdown: tables, task lists, footnotes, alerts
  • TeX math, typeset in embedded fonts
  • Code in 29 languages and Mermaid flowcharts, sequence and pie charts
  • PNG, JPEG, and SVG images
  • Tables of contents, themes, headers, footers, and covers
  • Books, Obsidian vaults, and batch folders
  • PDF/A-3b archives and tagged PDF/UA-1

Use a broader engine for

  • HTML and CSS layout
  • JavaScript-rendered pages
  • Complete LaTeX: packages, macros, numbering
  • Citations, bibliographies, and filters
  • Right-to-left scripts
  • Mermaid beyond flowcharts, sequence diagrams, and pie charts

Optional reversible profile

Exact source in. Exact source out.

RayoMD can attach the original UTF-8 Markdown to its PDF in the rayomd-source/1 profile, check its length and SHA-256 integrity, and recover it byte for byte later.

rayomd --export report.md archive.pdf --embed-source rayomd --inspect-source archive.pdf rayomd --recover-source archive.pdf recovered.md
Understand the format and limits
Source disclosure

Embedding is off by default. A reversible PDF exposes the complete Markdown source, including content not visible on rendered pages.
